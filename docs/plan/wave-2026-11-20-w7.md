## Where the plan goes against the verb

The verb puts the two stories in different waves because both list
`crates/canon/src/model/mod.rs` and `ess/domains/protocol.yaml`. The plan runs them together
(plan page § Replan 8) with both files split:

- `crates/canon/src/model/mod.rs`: story:protocol-writer adds one `mod write;` line and one
  `pub use write::write;` line. story:simulate-record-groups adds the struct `RecordGroup` and
  the field `records_together` on `Action`.
- `ess/domains/protocol.yaml`: story:protocol-writer edits the header comment (lines 2 and 3).
  story:simulate-record-groups adds a type and a field of `canon.protocol.Action`.

One dependency the split does not remove: the writer of story:protocol-writer destructures every
model struct with no `..`, so it stops compiling when `Action` gains a field. The order is fixed
for that reason: story:protocol-writer merges first; the unit of story:simulate-record-groups
then merges the wave branch into its branch, adds its field to `model/write.rs` and shows the
writer's coverage test green.

Changed on 2026-11-21: the adversary pass on story:simulate-record-groups runs before that
follow-up, on the unit's own branch, so the two units' reviews run at the same time. The
follow-up adds one field to one function of the writer, and the coordinator reads its diff. The
same follow-up moves `fixtures/investigation/record-group/chain/` out of
`fixtures/investigation/`, as `fixtures/child-outcome-large` was moved: inside that directory the
fixture adds about 65 s to the test over every investigation fixture.

One figure of story:simulate-record-groups (§ Decided, condition 2: 405 reachable states and 35
findings standing for 89 states) came from a Python walk. The unit pins the line the Rust binary
prints; if it differs, the unit reports the difference and the `sdc` session decides.

### What this wave left for later

- `canon validate` accepts a kind repeated inside one group (`kinds: [a, a, b]`) and counts it
  once; the story does not say whether a repeat is a mistake worth a refusal.
- The escape rule of the writer is a copy of the one in `generate::quote`; the two sets are equal
  today and nothing holds them equal.
- A grouped kind that declares `supplied_by` or `max_age` can stand alone in a walked state (the
  supplied step adds it alone, an expiry removes one member). The story allows both and the
  module docs state them; a protocol author reads it in the reference, not in a finding.
- Wave 8 is story:simulate-revise-step. story:decision-condition is `proposed`; its four open
  choices go to the `sdc` session before it is accepted.
